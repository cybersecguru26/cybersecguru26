# CyberSecGuru26

**Building CyberBrain26** — a local-first AI orchestration prototype with a focus on security.

## About | English

I am building CyberBrain26, a vendor-neutral project exploring how AI agents can be orchestrated with clear identity, policy, permission, approval, and audit boundaries.

The project is an experimental Python prototype. It includes model routing, agent orchestration, security decision components, and a Linux Bubblewrap execution path. It is not production-ready, and its security controls are not a certification or guarantee.

**Current focus:** strengthening execution isolation, durable records, and repeatable quality checks.

## O mně | Česky

Tvořím CyberBrain26, nezávislý projekt zkoumající, jak řídit AI agenty s jasně oddělenou identitou, pravidly, oprávněními, schvalováním a auditem.

Jde o experimentální prototyp v Pythonu. Obsahuje směrování modelů, orchestraci agentů, bezpečnostní rozhodovací komponenty a cestu pro spouštění v Linuxovém sandboxu Bubblewrap. Projekt není připravený pro produkční nasazení a jeho bezpečnostní prvky nejsou certifikací ani zárukou.

**Na čem pracuji:** posílení izolace spouštění, trvalé ukládání záznamů a opakovatelné kontroly kvality.
